🛠️ 技术架构

前端框架: Flutter Desktop 3.24.0
编程语言: Dart 3.5.0
AI引擎: TensorFlow Lite + ONNX Runtime
PPT生成: flutter_pptx / dart_pptx
状态管理: Riverpod
本地存储: Hive + SQLite
音频处理: flutter_sound + just_audio
视频处理: video_player + ffmpeg
